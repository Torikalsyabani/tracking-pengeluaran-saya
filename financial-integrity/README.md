# Financial Integrity 💰

Aplikasi manajemen keuangan pribadi berbasis web. Tidak memerlukan backend — semua data tersimpan di `localStorage` browser.

## Fitur

- Dashboard ringkasan bulanan (pemasukan, pengeluaran, saldo)
- Manajemen transaksi (tambah, edit, hapus)
- Kategori kustom
- Budget & limit pengeluaran
- Laporan & ekspor data
- Notifikasi budget terlampaui

## Demo

> Deploy via Vercel: [https://your-app.vercel.app](https://your-app.vercel.app)

## Cara Menjalankan Lokal

Cukup buka file `index.html` di browser, atau gunakan live server:

```bash
npx serve .
```

## Deploy ke Vercel

```bash
npm i -g vercel
vercel
```

Atau drag & drop folder ini ke [vercel.com/new](https://vercel.com/new).

## Teknologi

- HTML5 + Vanilla JavaScript
- Tailwind CSS (via CDN)
- Google Fonts & Material Symbols
- localStorage (penyimpanan data di browser)
